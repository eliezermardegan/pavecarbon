# Pavicarbon Website V1

Landing page estática para o estágio inicial da Pavicarbon.

## Objetivo
- comunicar diretamente com fabricantes de pavimentos intertravados;
- atrair fornecedores de biochar/materiais;
- apresentar a oportunidade sem abrir e-commerce;
- tratar detalhes comerciais por contacto direto;
- evitar claims de certificação, créditos ou desempenho antes de existir evidência.

## Publicar no GitHub Pages
1. Criar um repositório (ex.: `pavicarbon-website`).
2. Subir `index.html`, `styles.css` e `script.js`.
3. Settings → Pages → Deploy from branch → `main` / root.
4. Associar `www.pavicarbon.com` em Custom domain.
5. Configurar o DNS conforme o GitHub Pages indicar.

## Antes de publicar
Trocar `partnerships@pavicarbon.com` pelo email comercial real, se necessário.
